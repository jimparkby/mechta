# «Мечта»: кассовая часть

Не трать на вредное — копи на мечту. Здесь модуль для кассовой программы, демо-касса для стенда и сервер для проверки.

| Папка | Что внутри |
|---|---|
| `pos-module/` | Модуль кассы `mechta-pos.js` + типы. Встраивается в кассу, см. [INTEGRATION.md](INTEGRATION.md) |
| `pos-demo/` | Демо-касса для планшета: USB/Bluetooth-сканер, коды маркировки, подсказка кассиру, приложение покупателя |
| `server/` | Ядро сервера из прототипа + HTTP-сервер с эмулятором терминала и банка |
| `test/` | Тесты модуля (`npm test`) |
| `index (5).html` | Исходный прототип |

## Запуск

```bash
npm start          # http://localhost:8080/pos-demo/
npm test           # 19 тестов, Node 18+
```

Демо-касса работает и без сервера: если `/api/health` не отвечает, та же логика сервера запускается прямо в браузере. Поэтому `pos-demo/` можно выложить на GitHub Pages как есть.

## Стенд

- Сканер в режиме клавиатуры: просто сканируйте, поле ввода выбирать не нужно.
- Незнакомый штрихкод (настоящий товар со стенда) → касса попросит название, цену и группу и запомнит товар на этом планшете. Постоянный список — в `server/catalog-extra.json`.
- «Приложение покупателя» в шапке: запреты, копилка, история остановленных покупок.
- Журнал «Обмен с сервером» показывает каждый запрос модуля — удобно объяснять схему из 7 шагов.
